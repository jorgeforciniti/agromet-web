EXTREMOS Y MEDIAS

Mapa de Temperaturas

Cada punto es una estación automática de la red EEAOC con el valor de la variable elegida en el período: la temperatura mínima o máxima absoluta (el valor extremo del período) o una de las medias. Se muestran todas las estaciones que tienen datos en el período, estén hoy en funcionamiento o no.

Las medias se calculan con los datos diarios: la mínima media es el promedio de las mínimas de cada día; la máxima media, el promedio de las máximas, y la media, el promedio de ambas.

El color sigue una escala fija, igual en todas las consultas, de −5 °C (azul) a 35 °C (rojo oscuro); los valores fuera de ese rango toman el color del extremo. Al tocar un punto se ven el valor y cuántos días del período tienen datos («Registros: X de N días»).

Atención: no hay un mínimo de días con datos para mostrar una estación. Las que tienen días sin datos se marcan con borde punteado; si les faltan muchos, el valor puede no representar todo el período.

Las estaciones sin dato de la variable no se muestran, y se descartan los valores fuera del rango de −25 a 50 °C. El mapa no estima valores entre estaciones.
